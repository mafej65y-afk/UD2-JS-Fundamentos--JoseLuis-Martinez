## Estructura

Cada carpeta contiene un `index.html` y un `script.js` enlazado como archivo externo
(`<script src="script.js"></script>`). Para ejecutar un ejercicio basta con abrir su
`index.html` en el navegador.

El ejercicio 12 incluye dos scripts: `script.js` (versión con `Date`) y
`script-temporal.js` (versión con la API `Temporal`, que carga un polyfill si el
navegador no la soporta).
